Integrations

React / Vue / Svelte Export to Image with SnapDOM

React / Vue / Svelte

// React (ejemplo)
import "orbit/dist/orbit.css";
import "orbit/dist/orbit.js"; // registra <o-arc/> <o-progress/>

export function OrbitGauge({ value = 72 }) {
  return (
    <div className="bigbang">
      <div className="gravity-spot">
        <div className="orbit-4">
          <o-progress value={value}></o-progress>
        </div>
      </div>
    </div>
  );
}

// Vue/Svelte: usar el custom element directamente (mismo HTML).

Export to Image (SnapDOM)

Capturá cualquier bloque Orbit como PNG/SVG.

import snapdom from "snapdom";
// Selecciona un nodo (por ejemplo, el gauge del Hero):
const el = document.querySelector(".hero-demo .bigbang");
// Exportá a PNG:
const imgDataUrl = await snapdom.toPng(el);
// o a SVG:
const svg = await snapdom.toSvg(el);
