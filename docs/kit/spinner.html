Spinner

<o-spinner> tells people something is loading, in five variants that share one size, speed and color.

Each variant is a small Orbit universe. The ring is two equal <o-arc>s turning at two paces, so the arc they draw together stretches and shrinks. Dots are satellites on one ring, segments are vectors, and the orbit variant turns two rings of satellites around a core. All of it moves with CSS, so a spinner runs no script while it turns.

Properties

NameWhat it does
valueThe progress value, kept in range, or undefined while there is none. Setting it writes the attribute; null removes it.
formatterA function (value, { kind, min, max }) => string for the readout and aria-valuetext. See Shared options.

Progress

When you know how far along a task is, say so. The progress ring turns while there is no value and fills once there is one, gliding from one value to the next.

Accessibility

The spinner has role="progressbar" and aria-busy="true", named by label (“Loading” by default; say what is loading). While there is no value it has no aria-valuenow, which is how a progress bar says it does not know how far along it is. With a value it gets aria-valuenow, aria-valuemin, aria-valuemax and an aria-valuetext in the number format, and aria-busy turns false at the end. Set role="status" yourself if the spinner should be announced as it appears; the spinner keeps it. It is never a tab stop.

With prefers-reduced-motion nothing turns or swells. The arcs, dots, ticks and moons stay in place and breathe slowly in and out, so the page still shows it is working, and a progress ring jumps straight to each new value.
