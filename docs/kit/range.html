Range

<o-range> is a circular range slider: two handles on one ring pick a start and an end, numbers or times of day.

The dial is a whole day, so the band wraps through midnight. The track and the band are two interactive <o-arc>s on orbit-12: the band's ring takes the start as its --o-from and the span as its value. Each handle is a satellite on the same lane, placed by its angle, and the hours are satellites spread around an inner ring.

Numbers

Without mode, the range is a pair of numbers between min and max on a 270° arc, and the end never comes before the start. The middle shows the span, formatted like any kit readout.

Properties and events

NameWhat it does
value"22:30-06:45" or "20-80". Setting it (also as [start, end]) fires no event.
start, endOne end each: "22:30" in time mode, a number otherwise.
spanThe distance from start to end, in values (minutes in time mode). Read only.
form, labels, defaultValue, validityAs on a native input.
formatterA function that writes the numbers. It also gets kind: 'span' for the readout in the middle.
inputFires on every change you make. event.detail has value, start, end and span.
changeFires once a drag ends with a different value, and on each key press.
 
sleep.addEventListener('change', (e) => save(e.detail.start, e.detail.end))

Accessibility

The range is a role="group" named by label (or “Time range” / “Range”), with two handles that are each a role="slider" and a tab stop, named by start-label and end-label. Each has aria-valuenow, aria-valuemin, aria-valuemax and an aria-valuetext that reads the time or number and the span, like “22:30, span 8 h 15 min”.

Arrow keys move the focused handle one step, Page Up and Page Down ten steps (an hour in time mode), Home and End go to the ends. Shift with an arrow moves both handles. A handle pushed past min-span or max-span carries the other one, so keys never get stuck.
