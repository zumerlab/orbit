Knob

<o-knob> is a rotary control you turn with the pointer, the wheel or the keyboard.

Grab the band and turn it, or drag up and down anywhere else on the knob. The track is an interactive <o-arc> with a hit-width, so it takes the pointer along its whole length, a few pixels past its edges too.

Properties and events

NameWhat it does
valueReads or sets the value. Setting it snaps and clamps like the attribute and fires no event, like a native input.
min, max, step, stepUp(), stepDown()As on <input type="range">.
form, labels, defaultValue, validityAs on a native input.
formatterA function that writes the readout and aria-valuetext. See Shared options.
inputFires on every change you make: turning, keys, the wheel. event.detail.value has the value.
changeFires once a gesture ends with a different value, and on each key press or wheel step.
 
knob.addEventListener('input', (e) => preview(e.detail.value))
knob.addEventListener('change', (e) => save(e.detail.value))
knob.value = 40

The knob is a form control. Inside a <form> with a name, it submits its value, resets with the form and comes back on page restore:

<form>
  <o-knob name="volume" value="30"></o-knob>
</form>

Accessibility

The knob is a role="slider" with aria-valuenow, aria-valuemin, aria-valuemax, aria-valuetext and aria-disabled. It is one tab stop. Arrow keys move one step, Page Up and Page Down ten, Home and End go to the ends. The wheel only turns it while it has focus, so scrolling the page never changes a value by accident.

Without a name it is called “Rotary control”, or takes its label. Give each knob an aria-label or aria-labelledby.
