Donut chart

Each category is an <o-arc value>. Values are shares of 100, and arcs stack in the order they appear in the HTML.

    How it's built

    • One ring on lane 9, three lanes thick, with --o-gap between segments.
    • interactive makes each segment hoverable; the rest of the square stays click-through.
    • Change a value and the following segments move along.
