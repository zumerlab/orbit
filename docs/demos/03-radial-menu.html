Radial menu

Six actions around a hub. Every wedge is the same distance from the pointer, which makes radial menus fast to use.

Hover, click, or use Tab and Enter.

How it's built

  • Six <o-arc> without value split the ring evenly. --o-gap and the thickness are set once, on the ring.
  • interactive lets the painted wedge receive the pointer; the rest of the square stays click-through.
  • Labels are satellites on a second ring of the same lane, turned half a wedge with --o-from.
  • The hover scale uses scale; Orbit positions arcs with rotate, so both apply.
