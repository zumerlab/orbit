Chronograph watch face

Each sub-dial is a whole clock inside a satellite, with its own center, ticks and hand. Start the stopwatch and three systems run at once.

How it's built

  • The three sub-dials are satellites on orbit-5. from-90 range-180 fit-range puts the first at three o'clock, the last at nine and one between. See rings.
  • --o-size-ratio: 6 on that ring makes each one six lanes wide. The .gravity-spot inside a satellite takes the satellite as its universe and starts from the defaults, so the sub-dial uses the same orbit-11 ticks and orbit-4 hand as a big clock. See satellites.
  • Every hand is one vector on a ring turned with rotate. The stopwatch only sets an angle per hand, sixty times a second while it runs.
  • The JS tab writes the ticks and the sub-dials, so the markup of a sub-dial appears once.
