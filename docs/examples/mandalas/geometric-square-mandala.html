Geometric square mandala

One pattern of nested squares, copied and turned. The copies sit on one ring, and Orbit spreads them over a quarter turn: pick the number of folds and the angles follow.

How it's built

  • Each copy is an at-center satellite with --o-size-ratio: 24, as wide as the universe. The .gravity-spot inside it has the same lanes as the main system. See satellites.
  • All copies sit on one orbit-0 with range-90. Orbit gives each one an angle, 90° divided by the number of copies, and spin-lock turns the copy by that angle.
  • A square is a satellite with the box class. at-center keeps it on the center, so only --o-size-ratio sets its size, in lanes.
  • The diamonds are squares with spin-lock angle-45: the same turn, for a single satellite.
